# Website Desa Makasari

## Tentang Project

Website Desa Makasari merupakan project kelompok yang dikembangkan sebagai bagian dari kegiatan KKN Riset 23E di Desa Makasari, Kecamatan Kalapanunggal.

Website ini dikembangkan sebagai media informasi digital untuk memperkenalkan profil desa dan menyajikan informasi kepada masyarakat.

## Teknologi

* HTML
* CSS
* JavaScript

## Kontribusi Saya

Saya berkontribusi dalam pengembangan tampilan antarmuka website, khususnya pada halaman Data dan Berita menggunakan HTML dan CSS. Saya juga terlibat dalam proses penyesuaian tampilan halaman berdasarkan desain yang telah dirancang.

## Status Project

Website telah melalui tahap pengembangan, tetapi saat ini belum dapat diakses melalui domain karena masih terdapat kendala pada server/VPS.

Repository ini digunakan sebagai dokumentasi source code project.
